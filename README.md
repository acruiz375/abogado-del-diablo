# abogado-del-diablo

Skill para Claude Code (y otros agentes compatibles con Agent Skills) que critica a fondo una idea, plan, pitch, documento o proyecto sin validar ni adular: asume que va a fracasar y lo demuestra por ocho ángulos (premisas, mercado, competencia, viabilidad, números, ejecución, pre-mortem y punto ciego), y entrega un veredicto franco con la lista priorizada de qué arreglar.

## Instalación

```bash
npx skills add acruiz375/abogado-del-diablo -g -y
```

## Uso

Escribe `/abogado-del-diablo` o frases como «hazme pedazos esto», «critica mi idea sin filtros», «dime por qué va a fallar», «pre-mortem».

## Contenido

- `SKILL.md`: instrucciones del skill.
- `references/angulos.md`: los ocho ángulos de crítica.
- `references/ejemplos.md`: ejemplos de veredictos.
